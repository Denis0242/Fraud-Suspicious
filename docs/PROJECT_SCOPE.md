# Project Scope
## Objective
Detect and prioritize fraud and suspicious transaction patterns using behavioral transaction features and explainable rules.

## Patterns
- Velocity spikes
- Unusual transaction amounts
- Geographic anomalies
- Rapid fund movement
- Account takeover indicators
- Repeated counterparty concentration
- Behavioral anomalies

## Workflow
Raw transactions → feature engineering → fraud risk scoring → pattern classification → alert generation → investigator queue → disposition → portfolio monitoring.

All data is synthetic.
